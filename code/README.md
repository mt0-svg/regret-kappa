# Code

The program that wrote the data of the Lean proof, and the records of the checks of the formal proof. The proof does not trust the program: the Lean kernel checks what it writes.

## Directories

| Directory       | Content                                                                                                                                                                                                                                                                                                     | Run                                                                                                                                | Time                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `drift-cells/`  | `drift_cells.gp` writes `RegretKappa/LowerSharp/DriftCells.lean`: the move table of Section 4.2 and, for each of its 28 cells, the subdivision of the drift certificate of Computation B.2, from the bisection trees of `drift_tree_lib.gp`, in exact rational arithmetic (PARI/GP 2.17.4)                  | `cd drift-cells && gp -q drift_cells.gp < /dev/null`, which writes the shipped module again, byte for byte (`out/drift_cells.txt`) | under a second                                                                                |
| `formal-proof/` | a clean build of the Lean package, the axioms of the theorems of `config.json` (`main_axioms.out`), and a Comparator run with its four negative controls (`comparator.out`, `comparator-control.out`, `comparator-control-closed.out`, `comparator-control-scalefree.out`, `comparator-control-everyt.out`) | `bash formal-proof/clean_build.sh`                                                                                                 | 11 min on three cores, Mathlib built (`clean_build.out`); Comparator 3 min (`comparator.out`) |
