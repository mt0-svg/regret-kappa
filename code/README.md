# Code

The programs behind the computations of the paper, each with its complete recorded output: Computation A.9 (the constants of Theorem 3.1), Computation B.2 (the drift inequality of Lemma B.1), the constants of Section 4, and the programs that write the data of the Lean proof. Lean proves every inequality the proofs use; these programs redo the certificates separately from Lean and compute the values quoted in the paper. Running times are those of the recorded rerun, `rerun/out/layout-pass1.txt`, on an AMD Ryzen 9 5900X (12 cores, 24 threads), 64 GB of memory, with PARI/GP 2.17.4 and SageMath 10.9.
